Czytnik pisma

Witaj! Jednorazowa konfiguracja

Aplikacja odczytuje pismo za pomocą sztucznej inteligencji Google (Gemini). Potrzebny jest do tego bezpłatny klucz. Wystarczy go wkleić raz, zostanie zapamiętany tylko na tym telefonie.

  1. Otwórz stronę aistudio.google.com/apikey i zaloguj się kontem Google.
  2. Kliknij Create API key (Utwórz klucz API).
  3. Skopiuj klucz (długi ciąg znaków zaczynający się zwykle od „AIza”) i wklej go poniżej.

Dodaj zdjęcie kartki

Możesz dodać kilka stron. Zostaną odczytane po kolei, jako jeden tekst.

Jak odczytać?

Odczytuję pismo…
To potrwa zwykle kilka do kilkunastu sekund.
Wielkość tekstu
Fragmenty oznaczone jako [nieczytelne] lub ze znakiem ? w nawiasie warto porównać z oryginałem. Tekst możesz tu poprawiać ręcznie.

Ostatnio odczytane

Przechowywane są tylko teksty (bez zdjęć), wyłącznie na tym telefonie. Ostatnie 30.

Model odczytu

Zostaw „Automatycznie”, chyba że odczyt przestanie działać. Aplikacja sama wybiera najnowszy darmowy model Gemini Flash.

O aplikacji

Zdjęcia są wysyłane do Google wyłącznie w celu odczytu i nie są zapisywane w aplikacji. Nie skanuj dokumentów z danymi wrażliwymi (np. numerami PESEL, danymi medycznymi).
